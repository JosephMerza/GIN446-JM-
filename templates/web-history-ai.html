History of the Web

Introduction

The web is a system that allows people to access websites and web pages in order to share information using the Internet. The web is a service that operates on the Internet. It was invented by Tim Berners-Lee at CERN. In 1990, the first website was operating at CERN.

Verified Milestones

1989: Foundation of the Web

Tim Berners-Lee invented the World Wide Web. He coined the term "World Wide Web," wrote the first World Wide Web server, "httpd," and the first client program, "Worldwide Web," in October 1990.

1991: Web is available outside CERN

The first servers were running outside of CERN by early 1991. Berners-Lee posted on the public alt.hypertext newsgroup. This is now considered to be the official start of the World Wide Web as a public project.

1993: Mosaic browser was released

NCSA released working versions of the Mosaic browser for all common platforms: X, PC/Windows, and Macintosh.

1994: World Wide Web Consortium (W3C) was established

In 1994, the decision to form the World Wide Web Consortium came at the urging of many companies investing increasing resources into the web. In founding the World Wide Web Consortium, Sir Tim Berners-Lee created a community of peers.

Three Key Technologies

HTML: HyperText Markup Language

HyperText Markup Language (HTML) is the document formatting language with the capability for hypertext links that became the primary publishing format for the Web.

HTTP: HyperText Transfer Protocol

HyperText Transfer Protocol (HTTP) is a protocol used to exchange web documents.

URL: Uniform Resource Locator

A Uniform Resource Locator (URL) is an address used to identify and locate resources on the Web.
